# CNN Image Classification

A deep learning image classification project built using **Python and PyTorch**. The project uses a Convolutional Neural Network (CNN) to classify images into different categories.

## Tech Stack

* Python
* PyTorch
* Torchvision
* NumPy
* Matplotlib
* Pillow
* Google Colab

## Project Workflow

1. Load and prepare the image dataset
2. Split the dataset into training and testing sets
3. Apply image transformations and normalization
4. Create PyTorch DataLoaders
5. Build a CNN model
6. Train the model
7. Evaluate model performance
8. Visualize predictions and results

## Dataset

The dataset is not included in this repository due to its size.

Download the dataset separately, extract it, and update the dataset path in the notebook before running the project.

## Notebook

The complete implementation is available in:

`CNN_Image_Classification.ipynb`

The notebook contains the data preprocessing, CNN architecture, training, evaluation, and prediction steps.
